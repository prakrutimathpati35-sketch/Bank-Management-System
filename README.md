# Bank Management System

## Project Overview

Bank Management System is a Java-based web application developed to manage basic banking operations. The system allows users to create an account, log in securely, view account details, deposit money, withdraw money, transfer money, and view transaction history.

## Technologies Used

- Java
- HTML
- CSS
- JavaScript
- JSP
- Servlets
- MySQL
- JDBC
- Apache Tomcat
- Eclipse IDE

## Features

- User Registration
- User Login
- Account Management
- View Account Details
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Logout

## Database

MySQL is used to store:

- Customer details
- Account information
- Transaction details
